# Как работать с Claude экономно

## Шаблон первого сообщения новой сессии
Проект: [название]. Прочитай CLAUDE.md и NEXT.md в корне репозитория.
Задача: [одна конкретная задача]. Отвечай коротко, код в чат не выводи — сразу меняй файлы.
В конце обнови NEXT.md (что сделано / что дальше) и сделай commit + push.

## Экономия лимитов
- Одна задача — одна новая сессия: длинная история делает каждое сообщение дороже.
- Пиши все пункты задачи одним сообщением.
- Большие обновления дели на 3–5 частей, по сессии на часть.
- Сборки и тяжёлую генерацию — один раз в конце.
- Скриншоты — только когда без них непонятно.
- Вопросы не по коду — в обычном чате, не в режиме кода.

## Модель и усилия
- Обычные задачи и баги: Sonnet + высокий (high).
- Мелочи (текст, цвет, цена): Sonnet + низкий.
- Очень большие переделки: Opus + средний.
- Opus + низкий не брать: дорого и думает слишком мало.
