# Specter

Чат-площадка в стиле Телеграма: личка, группы, ссылки-приглашения, стикеры, гифки, действия (пнуть, обнять, пощекотать...), ИИ-собеседник Спек и админка.

## Запуск на компьютере

Нужен Node.js 20 или новее.

Сначала сделай копию `.env.example` с именем `.env` и впиши туда `ADMIN_PASSWORD` и `JWT_SECRET` (любая длинная случайная строка). Без пароля вход админа выключен.

```
npm install
npm run dev
```

Открой http://localhost:5173

Без `DATABASE_URL` база создаётся сама в папке `data/` (встроенный Postgres), ничего ставить не надо.

Собрать и запустить как на сервере:

```
npm run build
npm start
```

Тогда сайт на http://localhost:3000

## Настройки (.env)

Пустые строки означают, что функция выключена.

| Переменная | Зачем |
|---|---|
| `ADMIN_LOGIN`, `ADMIN_PASSWORD` | вход админа (кнопка «Вход для админа» на экране входа) |
| `JWT_SECRET` | ключ сессий, держи в секрете |
| `DATABASE_URL` | Postgres, например Neon. Пусто = локальная база в `data/` |
| `GROQ_API_KEY` | включает ИИ Спека (ключ на console.groq.com) |
| `GOOGLE_CLIENT_ID` | вход через Google (console.cloud.google.com → Credentials → OAuth Client ID, тип Web, в Authorized JavaScript origins добавить адрес сайта) |
| `GIPHY_API_KEY` | поиск гифок (developers.giphy.com) |
| `SMTP_*` | отправка кодов на почту. Для Gmail нужен «пароль приложения». Пока SMTP пустой и режим development, код печатается в консоль сервера |

## Как всё устроено

- **Вход**: Google, код на почту (6 цифр, живёт 10 минут, 5 попыток), гость или админ.
- **Гость** ничего не сохраняет: при выходе удаляются его сообщения, личка и файлы. Брошенные гостевые аккаунты чистятся сами через 2 дня. Гость может зарегистрироваться из меню.
- **Ссылка на группу** `/join/...`: кто перейдёт без аккаунта, сразу становится гостем и попадает в группу. Ссылку можно сбросить в инфо группы.
- **Права группы** (гости пишут или нет, фото, стикеры, GIF, ИИ, 18+, медленный режим, мут, кик, бан) меняет только админ. Создатель группы может менять название, аватар и ссылку.
- **Действия**: `/пнуть @ник` или правый клик по сообщению → Действие. Все команды в `/help`.
- **18+ команды** работают только в группах, где админ их включил, и только между теми, кто отметил «Мне есть 18» в профиле. Гостям недоступны, в `/help` появляются только у тех, кому можно.
- **Стикеры**: встроенный пак эмодзи-стикеров + свои паки (меню → Мои стикеры). Чужой пак можно сохранить через правый клик по стикеру.
- **Спек (ИИ)** отвечает в личке, в группе на `@spec`, `/спек вопрос`, ответ на его сообщение, а иногда влезает сам (частота в админке). Учится манере общения: берёт случайные фразы из групп, где он включён (без гостей, ссылок и длинных чисел), их видно и можно удалить в админке.

## Безопасность

- Сессия в httpOnly-куке, SameSite=Lax, Secure в продакшене
- Пароль админа хранится только в `.env`, сверяется через bcrypt, вход ограничен 5 попытками за 15 минут
- Лимиты запросов на вход, коды, загрузку файлов и отправку сообщений (антиспам)
- Проверка Origin на все изменяющие запросы (защита от CSRF)
- Все данные проверяются через zod, SQL только с параметрами
- Файлы проверяются по содержимому (PNG, JPG, WEBP, GIF, до 5 МБ), отдаются с nosniff и отдельной CSP
- Helmet: строгая CSP, запрет встраивания в iframe, HSTS
- Текст рендерится без HTML, ссылки открываются с noopener
- Гифки принимаются только с giphy.com

## Выкладка на Render + Neon (бесплатно)

1. Залей проект на GitHub (`.env` в git не попадёт)
2. На neon.tech создай базу, скопируй connection string
3. На render.com: New → Blueprint → выбери репозиторий (там уже есть `render.yaml`)
4. Заполни переменные: `ADMIN_PASSWORD`, `DATABASE_URL`, `APP_URL` (адрес сайта на Render) и нужные ключи
